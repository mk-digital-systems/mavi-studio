# Yerel yazı tipleri

Hepsi serbest lisanslıdır (çoğu **SIL Açık Font Lisansı 1.1**, Special Elite **Apache 2.0**); projeye gömülmesi ve videoya yazılması serbesttir. Kaynak: Google Fonts deposu (github.com/google/fonts), 2026-11-12'de indirildi. Her fontun lisans metni yanındaki `OFL-*.txt` / `LICENSE-*.txt` dosyalarındadır.

Dosyalar yalnızca Latin harflerini (Türkçe ğ ş ı İ ö ü ç â î û dahil) içerecek biçimde `fontTools.subset` ile küçültülüp woff2'ye çevrildi; harf şekilleri değiştirilmedi. Her fontta Türkçe karakterler tek tek denetlendi. **Ğ, ğ, Ş, ş, İ eksik olan fontlar (ör. Fredoka, Orbitron, Permanent Marker, Rye, Creepster) bilerek eklenmedi.**
